# study_notes

This directory stores study notes that support SPICEUnion development.

## Files

- `C++标准开发配置.md`: notes about the baseline configuration expected in a
  modern C++ project, especially when using VSCode with CMake.

## Naming Rules

- Use stable topic names.
- Do not use phase-only names such as `new`, `final`, `tmp`, `test2`, or `v2`.
- Notes should explain reusable engineering practice, not one-off command
  history.
