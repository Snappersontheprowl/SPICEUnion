# study_notes

本目录存放支持 SPICEUnion 开发的学习笔记。

## 文件

- `C++标准开发配置.md`：现代 C++ 项目应具备的基础开发配置笔记，重点面向
  VSCode + CMake 使用场景。
- `SPICEUnion开发环境配置.md`：本仓库实际使用的 VSCode / CMake / clangd 配置。
- `当前已有插件.md`：当前 VSCode Remote SSH 环境中已安装插件及其作用说明。

## 命名规则

- 使用稳定主题名。
- 不使用 `new`、`final`、`tmp`、`test2`、`v2` 这类阶段性名称。
- 笔记应解释可复用的工程实践，而不是只记录一次性的命令历史。
