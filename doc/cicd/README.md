# cicd 说明

## 功能

- 存放 CI/CD 学习与落地方案：学习计划、学习笔记；后续可追加复盘、掌握度检查与
  错题/卡点记录。
- 面向 GitHub Actions 在 SPICEUnion 上的真实落地（两级流水线：云 runner 无 EDA +
  自托管 runner 有 EDA）。
- 本目录不是开发事实源；项目验证数字与能力边界以
  `../develop_doc/当前事实状态.md` 为准。

## 本级模块职责

- `CICD学习计划.md`：目标、起点自检、能力拆解、阶段计划、里程碑与验收标准。
- `CICD学习笔记.md`：概念词汇、最小 workflow 示例、官方文档锚点与常见误区
  （可持续追加）。

## 命名规则

- 学习文件按主题命名：`<主题>学习计划.md`、`<主题>学习笔记.md`、
  `<主题>复盘.md`、`<主题>掌握度检查.md`、`<主题>错题记录.md`。
- 不使用 `new`、`final`、`tmp`、`test2`、`v2` 这类阶段性词。

## 当前约定

- 事实依据标注来源（GitHub Docs 等官方文档）；教学取舍与工程策略明确标注
  “建议”。
- 真正落地到 SPICEUnion 的 CI 配置放在 `.github/workflows/`，本目录只保留学习
  与方案说明，不复制配置正文，避免双版本维护。
