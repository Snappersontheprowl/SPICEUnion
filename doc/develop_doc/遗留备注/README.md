# 遗留备注说明

## 功能

- 本目录存放 SPICEUnion 开发过程中需要保留但不适合进入主线文档的备注、外部调研和暂缓问题。
- 本目录不作为当前事实状态、开发路线或阶段完成定义的单一事实来源。

## 本级模块职责

- `libpsf上游候选备注.md`：记录 M2 result reader 相关的 libpsf 上游来源、维护状态、接入判断和后续验证建议。

## 命名规则

- 文件名使用稳定主题名，优先采用 `<主题>备注.md` 或 `<主题>上游候选备注.md`。
- 不使用 `tmp`、`new`、`final`、`v2` 这类阶段性词。

## 当前约定

- 本目录内容可以保留判断过程和外部链接，但必须标明最后验证日期。
- 若某条备注变成正式开发决策，应提炼后同步到对应主文档，例如 `M2.md`、`当前事实状态.md` 或 `开发路线图.md`。
- 若外部链接或判断长期失效，应更新备注或归档删除。
