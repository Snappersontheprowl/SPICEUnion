# 10_阶段记录

本目录存放 SPICEUnion 已完成或阶段性收口的开发记录。阶段文档用于追溯设计背景和阶段契约，
不替代 `../00_项目总览/01_当前事实状态.md`。

## 本级模块职责

- `01_M1_Spectre执行层.md`：Spectre 执行层、Evaluator、SimulatorSession、TaskResult 与 batch 契约。
- `02_M2_ResultIR与结果读取.md`：ResultIR、结果读取、libpsf backend、fixture 与结果层边界。
- `03_M3_多仿真器与语义收敛.md`：Ngspice 接入、跨 backend 结果语义对照和 M3 收口。
- `04_M4_语言绑定.md`：pybind11、C ABI 评估、语言绑定边界和 M4 后续项。

## 命名规则

- 阶段文档使用 `<序号>_<里程碑>_<主题>.md`。
- 里程碑标识如 `M1`、`M2` 保留，方便和代码、测试、事实状态中的阶段描述对应。

## 当前约定

- 若阶段文档与当前代码或主线事实冲突，以 `../00_项目总览/01_当前事实状态.md` 为准。
- 新阶段只有进入正式开发并需要长期追溯时，才在本目录新增文档。
