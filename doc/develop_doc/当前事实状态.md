# SPICEUnion 当前事实状态

更新时间：2026-08-06

## 项目定位

SPICEUnion 是 C++17 仿真器执行与结果读取基础设施库。

| 范围内 | 范围外 |
|---|---|
| batch 参数状态执行 | circuit metric / objective / penalty |
| worker 工作目录隔离 | optimizer |
| 输入顺序保序返回 | PDK 内容管理 |
| Spectre interactive backend | GUI |
| Ngspice batch backend | 完整 netlist IR |
| 最小 ResultIR 与结果读取 helper | Hspice / Xyce backend |

## 当前已实现能力

### 执行层

- `Evaluator` 支持 batch execution facade。
- batch 结果按输入顺序返回。
- worker 使用独立 work directory。
- 单任务失败不会破坏其他任务结果。
- startup failure、timeout、transport failure、simulation failure 有标准 `TaskStatus`。
- `SpectreSession` 支持 `spectre +interactive`：
  - SKILL handshake；
  - circuit handle 初始化；
  - 参数写入；
  - `(sclRun "all")`；
  - completion 判断；
  - graceful / force stop。
- `NgspiceSession` 支持 `ngspice -b` batch mode。

### ResultIR：`include/su/result.hpp`

| 类型 | 含义 |
|---|---|
| `ScalarResult` | 单 signal 标量 |
| `DcSweep` | 单 sweep axis、单 signal 实数响应 |
| `AcResponse` | frequency + complex response |
| `AcDerivedView` | magnitude dB + phase deg 派生视图 |
| `TranWaveform` | time/value 波形 |
| `SensitivityEntry` | legacy sensitivity 原始条目结构 |
| `ReadResult<T>` | 带显式 `ResultStatus` 的读取结果 |

### Result helper

已实现：

- `.raw` 目录定位；
- `dcOp.dc` 单 signal 标量读取；
- swept complex PSF 读取；
- 普通 time-sweep PSF transient 读取；
- AC magnitude / phase 派生；
- UGBW / phase margin；
- settling time；
- Ngspice `wrdata` AC / TRAN / DC sweep 文本读取。

libpsf 事实：

| 项 | 状态 |
|---|---|
| backend | 可选内部 backend |
| 默认构建 | 不编译、不链接 |
| 启用开关 | `SPICEUNION_ENABLE_LIBPSF_READER=ON` |
| 公开 API | 不暴露 libpsf 类型 |
| 本机默认路径 | `local/external/libpsf/install` |

### Spectre backend

当前已验证：

- interactive handshake / stop；
- single-task `(sclRun "all")`；
- evaluator multi-worker batch；
- PSF `dcOp.dc` scalar fixture；
- PSF `ac.ac` / `stb.stb` swept complex fixture；
- 普通 PSF transient fixture；
- Spectre RC low-pass AC fixture 可读入 `AcResponse`；
- Spectre RC charging TRAN fixture 可读入 `TranWaveform`。

当前边界：

- Spectre 23.1 PSFXL transient fixture 当前明确返回 `kUnsupportedFormat`。
- legacy sensitivity 仍未实现。
- Spectre 侧 DC sweep 与 Ngspice `DcSweep` 尚未做同类对照。

### Ngspice backend

当前 `NgspiceBuiltinTask` 输出映射：

| 任务 | 输出文件 | 输出格式 | ResultIR |
|---|---|---|---|
| `kRcAc` | `rc_ac.out` | 三列 `frequency real imag` | `AcResponse` |
| `kRcTran` | `rc_tran.out` | 两列 `time value` | `TranWaveform` |
| `kResistorDividerDc` | `resistor_divider_dc.out` | 两列 `sweep_value value` | `DcSweep` |

当前 external 测试会真实调用 Ngspice 并验证：

- RC AC 的 -3 dB 频率；
- RC TRAN 的 `τ` / `5τ` 充电曲线；
- 电阻分压 DC sweep 的分压比例。
