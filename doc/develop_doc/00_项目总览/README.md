# 00_项目总览

本目录存放 SPICEUnion 当前主线文档。这里的文档优先级高于阶段记录、专题记录和归档备注。

## 本级模块职责

- `00_项目章程.md`：项目定位、范围边界、长期原则和里程碑摘要。
- `01_当前事实状态.md`：当前已实现能力、验证结果、fixture、backend 状态和未实现边界的唯一事实总账。
- `02_架构总览.md`：当前已落地的分层架构、执行链路、结果读取链路和模块责任图。
- `03_开发路线图.md`：下一步施工任务、进入条件、完成定义、暂缓条件和验证矩阵。

## 命名规则

- 使用两位数字前缀固定阅读顺序。
- 文件名使用稳定业务语义，不使用阶段性名称。

## 当前约定

- 判断当前项目状态时，以 `01_当前事实状态.md` 为准。
- 判断当前模块关系时，以 `02_架构总览.md` 为准。
- 判断下一步施工时，以 `03_开发路线图.md` 和根 `TODO` 为准。
