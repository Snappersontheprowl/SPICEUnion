# develop_doc

本目录保留 SPICEUnion 当前开发事实、开发计划、后续路线、专项路线与简历材料。

## 文件

- `当前事实状态.md`：当前已实现能力、验证结果、fixture 来源与未实现边界。
- `CPP版本开发计划书.md`：项目范围、架构边界、行为基线与后续开发目标。
- `开发路线图.md`：阶段状态、后续任务、产出与完成定义。
- `OrderedConcurrentPool开发路线图.md`：OrderedConcurrentPool 从内部 pool 抽离为独立项目的阶段路线、边界与装配方式。
- `简历亮点解析.md`：基于项目能力整理的简历表达、面试口径与风险红线。

## 规则

- 事实、计划和路线优先保持精简。
- 简历材料允许单独保留，但不得把未实测或未完成事项写成完成事实。
- 不保留探索过程或已过时阶段流水账。
- 新增开发文档前，优先判断是否可以合并进现有入口文档。
