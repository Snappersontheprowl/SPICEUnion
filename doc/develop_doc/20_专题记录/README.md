# 20_专题记录

本目录存放跨阶段专项文档。专题文档可以记录专项边界、装配关系、验证入口和后续限制。

## 本级模块职责

- `01_OrderedConcurrentPool专项.md`：OrderedConcurrentPool 独立化专项的边界、装配方式、验证入口和后续限制。
- `02_用户工作流API设计.md`：统一用户工作流 API 的目标、边界、API 草案、失败语义和开发切分。

## 命名规则

- 专题文档使用 `<序号>_<稳定主题名>.md`。
- 不使用 `new`、`final`、`tmp`、`v2` 等阶段性词。

## 当前约定

- 专题文档不替代 `../00_项目总览/01_当前事实状态.md`。
- 专题若改变主线能力、架构或路线，必须同步更新 `../00_项目总览/` 下对应文档。
